02. Веб сайт хэрхэн ажилладаг вэ?

Веб сайт бүтээхэд гурван үндсэн технологи ашиглана.

HTML

Вебийн бүтэц, гарчиг, текст, зураг.

<h1>Сайн уу!</h1>

CSS

Өнгө, фонт, зай, байрлал.

color: blue;

JavaScript

Товч, тооцоолол, интерактив үйлдэл.

alert("Сайн уу!");
🏠 Зүйрлэл: HTML — байшин, CSS — чимэглэл, JavaScript — гэрлийн унтраалга.

03. HTML гэж юу вэ?

HTML нь веб хуудсанд агуулга оруулах тэмдэглэгээний хэл юм.

<h1>Миний сайт</h1>
<p>Би HTML сурч байна.</p>
<button>Дарна уу</button>

Миний сайт

Би HTML сурч байна.

✍ Дасгал: Гарчгийг өөрийн нэрээр солиорой.

04. HTML баримтын үндсэн бүтэц

HTML файл бүр ерөнхийдөө дараах бүтэцтэй байна.

<!DOCTYPE html>
<html lang="mn">
<head>
  <meta charset="UTF-8">
  <title>Миний сайт</title>
</head>
<body>
  <h1>Сайн байна уу!</h1>
</body>
</html>
  • head: хуудасны тохиргоо.
  • body: дэлгэц дээр харагдах агуулга.
  • title: браузерын таб дээрх нэр.
Дасгал: title хэсгийн нэрийг өөрчил.

05. Гарчиг, текст, холбоос, зураг

<h1>Миний танилцуулга</h1>
<p>Би ахлах ангийн сурагч.</p>
<a href="https://example.com">
  Сайт нээх
</a>
<img src="zurag.jpg" alt="Миний зураг">
  • h1 — гол гарчиг.
  • p — догол мөр.
  • a — холбоос.
  • img — зураг.
Дасгал: Өөрийн дуртай хичээлийн тухай текст бич.

06. Жагсаалт, хүснэгт, товч

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<button>Эхлэх</button>
  • ul — жагсаалт.
  • li — жагсаалтын нэг мөр.
  • button — товч.
Дасгал: Өөрийн сонирхдог 3 зүйлээр жагсаалт үүсгэ.

07. CSS гэж юу вэ?

CSS нь вебийн өнгө, фонт, хэмжээ, байрлалыг өөрчилдөг.

h1 {
  color: blue;
  text-align: center;
}

p {
  font-size: 20px;
}

Миний веб сайт

Энэ бол CSS-ийн жишээ.

Дасгал: blue өнгийг red болгож турш.

08. CSS-ийг HTML-тэй холбох

HTML-ийн head хэсэгт CSS файлыг холбоно.

<link rel="stylesheet"
      href="style.css">

style.css файлд:

body {
  font-family: Arial, sans-serif;
  background-color: #eff6ff;
}

h1 {
  color: #2563eb;
}
Дасгал: Дэвсгэрийг цайвар ногоон болго.

09. Margin, padding, border

Margin

Элементийн гаднах зай.

Padding

Элементийн доторх зай.

Border

Элементийн хүрээ.

.card {
  margin: 20px;
  padding: 16px;
  border: 2px solid blue;
  border-radius: 12px;
}
Дасгал: padding-ийг 10px болгон өөрчил.

10. Flexbox ба responsive дизайн

Flexbox нь элементүүдийг нэг мөр эсвэл баганаар байрлуулахад тусална.

.menu {
  display: flex;
  gap: 16px;
}

@media (max-width: 600px) {
  .menu {
    flex-direction: column;
  }
}
  • display: flex — уян хатан байрлал.
  • gap — элемент хоорондын зай.
  • @media — дэлгэцийн хэмжээнд тохируулах.
Дасгал: Жижиг дэлгэц дээр цэсийг босоо болго.

11. JavaScript гэж юу вэ?

JavaScript нь веб хуудсанд үйлдэл нэмдэг.

alert("Сайн байна уу!");
Товч дарах, оноо бодох, шалгалт шалгах зэрэгт ашиглана.
Дасгал: alert доторх текстийг өөрчил.

12. Хувьсагч ба өгөгдлийн төрөл

let name = "Болд";
let age = 16;
const isStudent = true;

console.log(name);
console.log(age);
  • let — утга нь өөрчлөгдөж болно.
  • const — дахин оноолт хийхгүй.
  • Текст — String, тоо — Number, үнэн/худал — Boolean.
Дасгал: Өөрийн нэр, насаа хувьсагчид хадгал.

13. Тооцоолол ба оператор

let a = 12;
let b = 5;

console.log(a + b); // 17
console.log(a - b); // 7
console.log(a * b); // 60
console.log(a / b); // 2.4
console.log(a % b); // 2

+ нэмэх, - хасах, * үржүүлэх, / хуваах, % үлдэгдэл.

Дасгал: 8 ба 4-ийн үржвэрийг console-д гарга.
Хариулт харахconsole.log(8 * 4);

14. if / else нөхцөл

let score = 75;

if (score >= 60) {
  console.log("Тэнцсэн");
} else {
  console.log("Дахин оролдоорой");
}

Нөхцөл үнэн бол if, худал бол else ажиллана.

Дасгал: Оноо 80-аас их бол “Сайн” гэж хэвлэ.
Хариулт харахif (score > 80) { console.log("Сайн"); }

15. Функц, давталт, үйл явдал

function greet() {
  alert("Сайн уу!");
}

for (let i = 1; i <= 3; i++) {
  console.log(i);
}
  • Функц — дахин ашиглаж болох код.
  • Давталт — үйлдлийг олон удаа хийх.
  • Event — товч дарах зэрэг үйл явдал.
Дасгал: 1-ээс 5 хүртэл тоог хэвлэ.
Хариулт харахfor (let i = 1; i <= 5; i++) console.log(i);
